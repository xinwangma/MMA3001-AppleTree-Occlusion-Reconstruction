# Dataset storage and provenance

The genuine Monash dataset is NOT included in this repository.

`raw/` stores downloaded original materials locally (excluded from Git).
`processed/` will contain derived arrays (excluded from Git).
`demo/` is created by `scripts/make_demo_manifest.py` and is a tiny **synthetic
format smoke-test only**, not an experiment on real apple trees.

See `docs/04_data_integration.md` before touching raw data.
